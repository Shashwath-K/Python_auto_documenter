Quick Start Guide

#

SemanticFlow runs entirely on local consumer hardware. Code never leaves your workstation, guaranteeing absolute privacy for proprietary intellectual property and personal projects.

💡
Prerequisites: Python 3.10+, and a running Ollama instance with the llama3.2:3b model pulled.

Installation in 3 Steps

Terminal / Bash 
# 1. Clone repository
git clone https://github.com/Shashwath-K/Python_auto_documenter.git
cd Python_auto_documenter

# 2. Install dependencies (FastAPI, NLTK, ReportLab, etc.)
pip install -r requirements.txt

# 3. Pull recommended local model & launch server
ollama pull llama3.2:3b
python -m uvicorn app.main:app --host 127.0.0.1 --port 8000 --reload

Once started, visit http://127.0.0.1:8000 to interact with the web workspace.

NLTK Text Preprocessing Pipeline

#

Integrated with the Natural Language Toolkit (NLTK), SemanticFlow includes a specialized NLP preprocessor designed for code comments, docstrings, and technical terminology.

NLTK Component Algorithm / Corpus Primary Function in AutoDoc
Word & Sent Tokenizer punkt & punkt_tab Segment raw code comments into discrete lexical units and sentence boundaries.
Stopword Filtering NLTK English Stopwords Eliminate high-frequency filler words (e.g. the, is, at, which) to highlight domain terms.
Morphology & Stemming Porter Stemmer Reduces inflected tokens to root stems (e.g. calculating, calculated → calcul).
Lemmatization WordNet Lemmatizer Preserves morphological validity with vocabulary grounding (e.g. matrices → matrix).
Lexical Diversity (TTR) Type-Token Ratio Ratio Calculates vocabulary richness: len(unique_tokens) / len(total_tokens).
ℹ️
Interactive Inspector: Press Ctrl+K anywhere in the application or click the NLP & NLTK header chip to inspect real-time metrics on the active editor contents.

Direct Python API Example

Python Example 
from app.services.text_preprocessing import preprocessor

# Preprocess raw technical code comments
raw_comment = "Calculates matrix eigenvalues and vectors using QR decomposition iteratively."
result = preprocessor.process(
    text=raw_comment,
    to_lower=True,
    remove_stopwords=True,
    lemmatization=True
)

print("Original Tokens:", result["original_token_count"])
print("Stopwords Filtered:", result["stopwords_removed"])
print("Lexical Diversity (TTR):", result["lexical_diversity"])
print("Top Keywords:", result["keywords"])
# Output: ['calculate', 'matrix', 'eigenvalue', 'vector', 'using', 'qr', 'decomposition', 'iteratively']

Live Mode & Ghost Typing

#

Live Mode provides an intelligent in-browser Monaco Editor that detects typing cadence. After you finish writing a function or class definition, the background daemon automatically analyzes intent and inserts formatted docstrings.

  • Context Menus: Right-click any highlighted code block and click Explain Code... to ask questions.
  • Configurable Density: Choose between Low (30%), Medium (50%), and High (100%) documentation density.
  • Language Support: Python, JavaScript, TypeScript, JSX, C/C++, Java, HTML, CSS, and Markdown.

File & Jupyter Notebooks

#

In File Upload Mode, you can upload standalone files or entire Jupyter Notebooks (.ipynb). AutoDoc inspects both code cells and markdown cells:

Jupyter Processing Logic 
// Notebook Cell Injection Pipeline
1. Parse JSON structure preserving metadata & cell execution counts
2. Target empty or undocumented code cells
3. Query local LLM heuristic engine
4. Re-inject docstring lines into cell source array
5. Re-render live preview or trigger PDF/DOCX conversion

Repo Scanner & Git Diffs

#

Repository Mode accepts a compressed .zip of any software project. It performs background extraction, scans for undocumented modules, injects documentation across files, and produces a real-time Git Diff viewer.

Once satisfied with the diff, click Commit & Download to obtain a pristine, fully documented copy with a personalized Git commit history.

REST API Reference

#

The backend exposes clean REST endpoints powered by FastAPI:

POST /api/nlp/preprocess

Applies NLTK tokenization, stopword filtering, and lemmatization to text or code comments.

Request Payload
{
  "text": "def calculate_velocity(distance, time): return distance / time",
  "to_lower": true,
  "remove_stopwords": true,
  "lemmatization": true,
  "is_code": true
}
GET /api/nlp/options

Returns available tokenizers, stemming models, and preprocessing filters.

POST /api/generate-comment

Generates PEP 257 compliant docstring or commented block using local Ollama.

POST /api/generate-ai-summary

Generates a comprehensive PDF or DOCX technical analysis report.
