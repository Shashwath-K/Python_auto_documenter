Quick start

#

Install the dependencies, start Ollama, then launch the server.

Needs: Python 3.10+ and an Ollama model such as llama3.2:3b.
Terminal
pip install -r requirements.txt
ollama pull llama3.2:3b
python -m uvicorn app.main:app --reload

Open 127.0.0.1:8000.

01

Find symbols and documentation gaps.

02
Prepare

Clean context with the NLP pass.

03
Generate

Ask the local Ollama model for output.

04
Export

Review, download, or commit the result.

NLP

#

The inspector tokenizes text, removes stopwords, and can lemmatize or stem terms before analysis. Use it when a document needs a cleaner vocabulary signal.
